## 2. Data, not widgets — the `Product` class

```dart
class Product {
  const Product({
    required this.name,
    required this.pricePaise,
    required this.unit,
    required this.category,
    required this.color,
  });

  final String name;        // 'Tomato'
  final int pricePaise;     // 4500 = Rs 45.00
  final String unit;        // 'kg' | 'pc' | 'bun'
  final String category;    // 'top' | 'regular' | 'slow'  (F2.6 chips)
  final Color color;

  bool get isWeighed => unit == 'kg';
  String get priceLabel => '₹${pricePaise ~/ 100}/$unit';   // "₹45/kg"
}

const List<Product> products = [
  Product(name: 'Tomato', pricePaise: 4500, unit: 'kg', category: 'top', color: Color(0xFFB91C1C)),
  ...
];
```

- One `Product` bundles five facts about one vegetable — instead of five separate lists.
- In **Stage 4** this becomes one row of the SQLite `products` table.
- **Money in paise (`int`)**: `4500`, not `45.0` — whole numbers are exact; a `double`
  drifts (`0.1 + 0.2 = 0.30000000000000004`). Rule from F1.4 / `01_PROJECT_CONTEXT.md`.

## 3. A list of data -> a grid of widgets

```
products = [Tomato, Potato, Onion, ...]          DATA
        |
GridView.builder(itemBuilder: tile for products[i])   ONE design, repeated
        |
[Tomato] [Potato] [Onion]
[Chilli] [Lemon ] [Palak]                        SCREEN
```

```dart
Expanded(
  child: GridView.builder(
    padding: const EdgeInsets.symmetric(horizontal: 16),
    gridDelegate: const SliverGridDelegateWithFixedCrossAxisCount(
      crossAxisCount: 3,          // 3 columns
      mainAxisSpacing: 12,        // gap between rows
      crossAxisSpacing: 12,       // gap between columns
      childAspectRatio: 0.95,     // tile width / height
    ),
    itemCount: products.length,
    itemBuilder: (context, index) {
      return _tile(products[index]);
    },
  ),
),
```

| Part | Meaning |
|---|---|
| `itemCount` | how many tiles in total |
| `itemBuilder: (context, index) { ... }` | **Flutter calls it** for each tile it needs, passing the position `index` (0, 1, 2...); it **returns the widget** for that position |
| `gridDelegate` | the grid's layout rules |
| `crossAxisCount: 3` | 3 columns (DESIGN.md: "3-column vegetable selection deck — do not build two") |
| `childAspectRatio` | width / height of each tile. 0.95 = slightly taller than wide, keeps the 88 px minimum tap target |

### Why `.builder` is fast
`GridView.builder` builds **only the tiles visible on screen**. With 200 vegetables it
builds about 12; as you scroll, it builds the new ones and throws away those that
scrolled off. Writing 200 tiles by hand would build all 200 at once.

### Why `Expanded`
A grid inside a `Column` has no height limit and would try to be infinitely tall —
error *"unbounded height"*. `Expanded` gives it **all the space left** under the weight
bar; the grid scrolls inside that space.

### One tile — `_tile(Product p)`
```dart
Container(
  decoration: BoxDecoration(
    color: p.color.withValues(alpha: 0.08),                  // light tint
    border: Border.all(
      color: p.color.withValues(alpha: p.isWeighed ? 0.25 : 0.7),
      width: p.isWeighed ? 1 : 2,                           // piece/bunch: thicker
    ),
    borderRadius: BorderRadius.circular(12),
  ),
  child: Column(
    mainAxisAlignment: MainAxisAlignment.center,
    children: [
      CircleAvatar(radius: 18, backgroundColor: p.color),
      const SizedBox(height: 8),
      Text(p.name, textAlign: TextAlign.center, ...),
      const SizedBox(height: 2),
      Text(p.priceLabel, style: TextStyle(fontFamily: 'monospace', color: p.color)),
    ],
  ),
)
```
- `withValues(alpha: 0.08)` — the same colour, 8% opaque (very light). 0 = invisible, 1 = solid.
- `CircleAvatar` — a filled circle (later: the vegetable's photo).
- Piece/bunch items should have **dashed** borders (wireframe). Flutter has no built-in
  dashed border, so a thicker border is used for now — on the polish list.

## 5. Stopping the stream — the initState / dispose pair

```dart
StreamSubscription<List<int>>? _weightSub;

_weightSub = weightChar.lastValueStream.listen((bytes) { ... });

@override
void dispose() {
  _weightSub?.cancel();      // stop listening when the screen closes
  super.dispose();
}
```
`listen()` returns a **subscription** — a ticket you keep so you can cancel later. Same
rule as the Timer in F1.4: **whatever you start, stop in `dispose`.** Without it the
stream would keep calling `setState` on a screen that no longer exists ->
`setState() called after dispose()`.

## 6. DART CONCEPTS USED HERE

| Feature | Syntax | Meaning |
|---|---|---|
| a class for your own data | `class Product { final String name; ... }` | bundles related facts into one object |
| getter | `bool get isWeighed => unit == 'kg';` | a value **calculated** when asked; used without `()`: `p.isWeighed` |
| integer division | `4500 ~/ 100` | `45` (int). `/` gives `45.0` (double) |
| const list of objects | `const List<Product> products = [ ... ];` | fixed at compile time; needs a `const` constructor |
| top-level variable | `products` outside any class | visible to any file that imports `product.dart` |
| callback with two parameters | `(context, index) { ... }` | Flutter passes both; `index` = which tile |
| list index | `products[index]` | the product at that position |
| `StreamSubscription<T>` | `_weightSub?.cancel()` | the handle returned by `listen`, used to stop it |

## 7. GATE — PASSED

**Q: What does `itemBuilder` do, and who calls it?** Flutter calls it with each index;
it returns the tile widget for that position.

**Q: Why is `GridView.builder` faster for 200 vegetables?** It builds only the tiles
visible on screen and builds the rest as you scroll — not all 200 at once.

**Q: Why store the price as `4500` paise in an `int`?** Whole numbers are exact; `double`
rupees drift, and money must be exact.
